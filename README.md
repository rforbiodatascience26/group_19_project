# On how to retrieve data

The data used in this project was collected from the [National Cancer Institute - GDC Data Portal](https://portal.gdc.cancer.gov/) via its Cohort Builder. All data belongs to the "Functional Genomic Landscape of Acute Myeloid Leukemia" project (BEATAML1.0-COHORT program). Due to the magnitude of data, only 84 cases and 75 files were selected among 826 cases and 16 794 files total.

A manifest for the selected cases and files can be found \[some location\]. To download these, upload the manifest by clicking "Import New Cohort" and upload file or simply paste the raw text containing the files.
